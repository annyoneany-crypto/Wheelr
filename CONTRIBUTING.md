# Contribute to Wheelr 🎡

Thank you for your interest in contributing to Wheelr! Here's how you can help us improve the tool for the crypto community.

## Getting Started
1. Check the open [Issues](https://github.com/annyoneany-crypto/Wheelr/issues) to see if there's anything we're already working on.
2. Open a new Issue if you find a bug or have an idea for a new feature.

## Pull Request
1. Fork the project.
2. Create a branch for your change (`git checkout -b feature/feature-name`).
3. Make sure the code is formatted correctly.
4. Submit a PR with a clear description of the changes.

## Code Guidelines
- We use **React** and **Tailwind CSS**.
- Try to keep components atomic and reusable.
- Comment on complex functions, especially those involving financial calculations (break-even, APY, etc.).

---
We're an open community, so any help is welcome!

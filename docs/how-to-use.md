## 👥 Adding Participants — Users Panel

The **Users** panel is where you manage names (entries) on the wheel.

### Adding Names

1. Open the **Users** settings panel
2. Type or paste names into the text area — **one name per line**
3. Names appear on the wheel **instantly** as you type

### Bulk Entry Options

| | Action | What It Does |
|:---:|---|---|
| ➕ | **Add repeated entries** | Add a name multiple times (e.g., "John × 5" = 5 slots) |
| 🔀 | **Shuffle** | Randomize the order of all entries |
| 🗑️ | **Clear all** | Remove every name from the wheel |
| ❌ | **Remove specific** | Delete a single entry by name |

> 💡 **Weighted odds:** More entries for a name = higher chance of winning. Use repeated entries to give weighted odds in your **random raffle wheel**.

## 🎡 Spinning the Wheel

### How to Spin

Click the **SPIN** button in the center of the wheel. The wheel spins for the configured duration and **gradually slows** to land on a random winner.

### ⏱️ Countdown

If enabled in Sound settings:

```
3️⃣ → 2️⃣ → 1️⃣ → 🎡 SPIN!
```

A countdown timer appears, an optional sound plays, and then the wheel spins automatically.

### Spin Duration

| Setting | Default | Effect |
|---|:---:|---|
| **Spin time** | 3 seconds | Shorter = quick picks, Longer = dramatic reveals |

## 🔧 Troubleshooting

| Issue | Solution |
|---|---|
| 🔇 Sound doesn't play | Click anywhere on the page first — browsers block autoplay until user interaction |
| 🔍 Wheel looks small | Reduce the visible wheel count to 1 for maximum size |
| ❓ Settings disappeared | You may have cleared browser data — use cloud sync to prevent loss |
| 🔗 Public link doesn't work | Make sure you saved the wheel to the cloud first |
| 🔤 Font not loading | Check internet connection — Google Fonts requires online access |

## Getting Started

1. Open [wheelr.xyz](https://wheelr.xyz) in any modern browser (Chrome, Firefox, Edge, Safari)
2. You'll see the **spinning wheel** in the center of the screen
3. The settings panels are accessible from buttons around the wheel
4. No account is needed — start customizing immediately

---

## Adding Participants (Users Panel)

The **Users** panel is where you manage the names (entries) on the wheel.

### Adding Names

- Open the **Users** settings panel
- Type or paste names into the text area — **one name per line**
- Names appear on the wheel instantly as you type

### Bulk Entry Options

| Action | What It Does |
|---|---|
| **Add repeated entries** | Add a name multiple times (e.g., "John × 5" gives John 5 slots) |
| **Shuffle** | Randomize the order of all entries |
| **Clear all** | Remove every name from the wheel |
| **Remove specific name** | Delete a single entry by name |

> **Tip:** More entries for a name = higher chance of winning. Use repeated entries to give weighted odds in your **random raffle wheel**.

## Spinning the Wheel

### How to Spin

Click the **SPIN** button in the center of the wheel. The wheel will spin for the configured duration and gradually slow down to land on a random winner.

### Countdown

If enabled in Sound settings:

1. A **countdown timer** appears (default: 3 seconds)
2. A countdown sound plays (if configured)
3. After the countdown, the wheel spins automatically

### Spin Duration

The default spin time is **3 seconds** (3000ms). You can adjust this to make the spin shorter or longer for more dramatic effect.

After each spin, the winner is added to the **Winner History** list.

### Configuration

| Setting | Options |

| **Panel position** | Left, Top, Right, or Bottom of the wheel |

### Actions

- View the full history of drawn winners
- **Remove** a winner from the list
- The panel can be hidden via the **UI Chrome toggle** for a clean presentation

## Sound Settings

The **Sound** panel lets you add custom audio to your **giveaway spinning wheel**.

### Audio Channels

| Sound | When It Plays |
|---|---|
| **Spin audio** | While the wheel is spinning |
| **Winner audio** | When the winner is announced |
| **Countdown audio** | During the pre-spin countdown |

### How to Set Custom Sounds

1. Open the **Sound** settings panel
2. Click the upload button for the desired audio channel
3. Select an audio file from your device (MP3, WAV, OGG, etc.)
4. The sound is stored locally in your browser — it persists across sessions

### Master Sound Toggle

Use the global **sound on/off** toggle to mute all audio instantly — useful when you need to quickly silence the wheel during a stream.

### Countdown Configuration

| Setting | Description |
|---|---|
| **Enable countdown** | Toggle the pre-spin countdown on or off |
| **Countdown start** | Set the starting number (default: 3) |

## Wheel Manager — Multiple Wheels

The **Wheel Manager** lets you create and manage multiple wheel configurations.

### Creating a New Wheel

1. Open the **Wheel Manager** panel
2. Click **Create New Wheel**
3. Enter a **name** and optional **description**
4. The new wheel starts with default settings

### Managing Wheels

| Action | Description |
|---|---|
| **Load** | Switch to a saved wheel — all settings update instantly |
| **Rename** | Change the name and description of any wheel |
| **Delete** | Permanently remove a wheel and its stored data |
| **Group** | Create parent-child relationships between wheels |

### Multi-Wheel Display

Display **1 to 4 wheels** simultaneously on screen:

- Set the visible wheel count in settings
- Each wheel can be independently configured
- Click on any individual wheel to spin it
- Wheels are arranged in a responsive grid layout

> **Use case:** Display a "Prize Category" wheel and a "Winner" wheel side by side for a two-step giveaway.

## Public Sharing & QR Codes

Share your wheel with others for **interactive live events**.

### Generating a Public Link

1. Save your wheel to the **cloud** (requires a free account)
2. A **public URL** is generated automatically
3. Share the link — anyone can open it and spin

### Public Wheel Features

- Read-only access — viewers **cannot** modify settings
- The wheel has an idle rotation animation when not spinning
- Responsive canvas adapts to the viewer's screen size

### QR Code

- Generate a **QR code** for your public wheel URL
- Display it on stage, in a presentation, or on stream
- Audience members scan with their phone to access the wheel instantly

> **Event tip:** Print the QR code on flyers or display it on a projector for trade shows and conferences.

## Account & Cloud Sync

### Creating an Account

Wheelr supports two sign-up methods:

- **Email and password** — classic registration
- **Google sign-in** — one-click OAuth via Google

### Cloud Features

Once logged in:

| Feature | Description |
|---|---|
| **Save to cloud** | Back up your complete wheel configuration |
| **Import from cloud** | Restore wheels on a new browser or device |
| **Cross-device sync** | Access the same wheels from any computer |
| **Automatic timestamps** | Track when wheels were last saved |

### Data Safety

- Cloud storage is **optional** — you can use Wheelr entirely offline
- Only you can access your saved wheels
- Wheel data is stored in Firebase Firestore under your user account

## Troubleshooting

| Issue | Solution |
|---|---|
| **Sound doesn't play** | Click anywhere on the page first — browsers block autoplay until user interaction |
| **Wheel looks small** | Reduce the visible wheel count to 1 for maximum size |
| **Settings disappeared** | You may have cleared browser data — use cloud sync to prevent data loss |
| **Public link doesn't work** | Make sure you've saved the wheel to the cloud first |
| **Font not loading** | Check your internet connection — Google Fonts requires online access |
